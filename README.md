# Zeroth

AI operations, built and handed over.

Zeroth rebuilds business processes so that agents run the steps and people keep the decisions. The approach is live in [Talent-Ray](https://talent-ray.com) (hiring), [Shipo](https://shipo.ai) (freight) and [Elefo](https://elefo.ai) (carbon).

The code behind them is private, so there is nothing to browse here. What we do and how to reach us is on [zeroth.company](https://zeroth.company). [Mehmet Kaya](https://github.com/KayaTheRock) runs it from Brussels.
